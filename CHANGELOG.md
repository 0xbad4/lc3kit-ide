# Changelog

## [1.0.0] - 2026-09-13

### Added

- Initial release of the LC3kit IDE.
- Qt 6 desktop application shell for LC-3 assembly development.
- Main workspace window with dockable panels for registers, flags, memory, logs, console, breakpoints, symbols, and settings.
- Multi-tab text editor workflow for managing multiple LC-3 assembly files.
- LC-3 syntax highlighting and editor customization through a custom lexer and QScintilla integration.
- Built-in assembly workflow for compiling LC-3 source into object output.
- VM execution and debugging tools integrated with the `lc3kit` core library.
- Support for breakpoints, stepping, and runtime inspection of machine state.
- Example LC-3 programs bundled in the app resources.
- Theme system with `charcoal` and `daisy` styles.
- Application manifest and app metadata for versioning, docs, source links, and example resources.
- Custom resource bundle for UI icons, fonts, and splash screen assets.
